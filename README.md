# Physics-Aware Symbolic Correction of the Ideal-Gas Law for CO₂

An interpretable, regime-aware symbolic regression model for approximating the
CO₂ compressibility correction over a documented thermodynamic domain.

The model learns

$$
Z = \frac{p}{\rho R T}, \qquad \Delta Z = Z - 1
$$

and predicts pressure with

$$
\hat p = \rho R T\left(1 + \widehat{\Delta Z}\right).
$$

## Scope

The reference labels in this repository are generated by CoolProp. Therefore,
the reported errors measure how accurately the symbolic model approximates the
selected CoolProp CO₂ equation of state; they are not an independent
experimental validation of CO₂ pressure.

The current study covers one fluid, CO₂, and should not be interpreted as a
general correction for every real gas.

## Method

The pipeline combines:

- CoolProp-generated CO₂ reference data
- a residual target, $\Delta Z$
- regime-specific symbolic regression with PySR
- a decision-tree regime gate
- soft-gated pressure inference

The regime labels use $|\Delta Z| \leq 0.03$:

- `near_ideal`: $|\Delta Z| \leq 0.03$
- `attraction_dominated`: $\Delta Z < -0.03$
- `excluded_volume_dominated`: $\Delta Z > 0.03$

These names describe the sign of the net compressibility residual. They are a
modeling interpretation, not a direct separation of microscopic interaction
energies.

The input features are reduced temperature and reduced molar density:

- $T_r = T/T_c$
- $\rho_r = \rho/\rho_c$

## Data splits and valid domain

The natural grid spans $T=310$–$500$ K and $\rho=100$–$20{,}000$ mol/m³.
Complete temperature isotherms are held out for validation and testing.

The stress grid spans $T=360$–$500$ K and $\rho=12{,}000$–$20{,}000$ mol/m³,
with separate held-out isotherms. It is a high-density distribution-shift and
denser-grid test, not an out-of-range extrapolation test, because it lies
inside the natural domain.

The deployable model should only be used inside the documented input domain.
The generated configuration and exact split manifest are written to
`configs/` by `01_CO2_Data_Generation.ipynb`.

## Held-out test results

Pointwise pressure MAPE and maximum pointwise relative error are shown below.
The maximum is included because the mean alone hides the error tail.

| Model | Natural MAPE | Natural max | Stress MAPE | Stress max |
|---|---:|---:|---:|---:|
| Ideal gas ($Z=1$) | 22.024% | 304.696% | 23.443% | 84.998% |
| Global symbolic | 2.494% | 66.326% | 1.713% | 5.804% |
| Oracle regime-specific | 0.378% | 9.064% | 0.351% | 3.513% |
| Hard gate | 0.391% | 9.064% | 0.421% | 5.781% |
| Final soft-gate model | **0.389%** | 9.064% | **0.391%** | 5.186% |

The `oracle_regime_specific` result uses the true regime label and is an upper
bound, not a deployable model. The deployable result is
`final_soft_gate_model`.

The detailed metrics are in
[`results/tables/final_test_comparison.csv`](results/tables/final_test_comparison.csv),
the held-out gate accuracy is in
[`results/tables/gate_test_summary.csv`](results/tables/gate_test_summary.csv),
and the ideal-gas baseline is in
[`results/tables/ideal_gas_baseline.csv`](results/tables/ideal_gas_baseline.csv).

## Inference sanity check

The tracked 20-point high-density sanity sample has:

- mean pressure error: 0.589%
- maximum pressure error: 3.350%

This is a small illustrative sample, not a replacement for the full held-out
test evaluation.

The inference notebook accepts temperature in K and molar density in mol/m³,
then returns the gate prediction, gate weights, predicted $Z$, and pressure in
Pa and MPa. It also rejects inputs outside the documented training domain.

## Reproducibility

The repository contains notebooks for the full workflow:

1. `01_CO2_Data_Generation.ipynb`
2. `02_Global_Symbolic_Regression.ipynb`
3. `03_Regime_Specific_Regression.ipynb`
4. `04_Regime_Gate.ipynb`
5. `05_Final_Inference.ipynb`

Each notebook loads its required persisted inputs instead of relying on Python
variables from another notebook. In Colab, Drive restoration is optional; a
local checkout with generated files works as well.

Install the pinned Python dependencies with:

```bash
python -m pip install -r requirements.txt
```

After generating the data and model artifacts, regenerate the tracked figures
with:

```bash
python src/validate_results.py
python src/generate_figures.py
```

The generated datasets and serialized PySR models are ignored because of their
size and binary/version sensitivity. `configs/experiment_config.json` records
the reference software and data-generation settings; model files should be
archived together with that configuration when reporting a final run.

## Limitations

- The labels and evaluation reference the same CoolProp source.
- Only CO₂ is studied.
- The stress split does not test extrapolation outside the natural domain.
- A future paper should report uncertainty across held-out isotherms and test
  equation stability across multiple PySR seeds.
- The symbolic experts and gate are intended for the documented domain only.
