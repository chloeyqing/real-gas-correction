# Generated data

The CSV files under `data/processed/` are generated by
`notebooks/01_CO2_Data_Generation.ipynb` and are intentionally ignored by Git.

Each row represents one CO₂ state point. Important columns are:

- `T_K`: temperature in K
- `rho_mol_m3`: molar density in mol/m³
- `p_real_Pa`: CoolProp reference pressure in Pa
- `p_ideal_Pa`: $\rho R T$ in Pa
- `T_reduced`: $T/T_c$
- `rho_reduced`: $\rho/\rho_c$
- `Z`: compressibility factor
- `delta_Z`: $Z-1$
- `phase`: phase label returned by CoolProp
- `regime`: residual-based regime label

The data are a deterministic reference-EOS grid, not experimental
measurements. The exact constants, grid settings, software version, and split
manifest are recorded in `configs/experiment_config.json` and the generated
`configs/split_manifest.json`.
